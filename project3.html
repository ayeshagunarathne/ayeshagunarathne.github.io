TranStain: Vision Transformer based histopathology image normalization (Center for Machine Vision and Signal Processing (CMVS) - ITEE, Oulu University)

CASE / 03
Research Digital Twins

Problem

Histopathology images vary widely in stain appearance across labs and scanners, which can hurt the performance of downstream deep learning models. TranStain addresses this with a stain normalization method for stain-style transfer.

Approach

The method uses a Residual Swin Transformer generator within a CycleGAN framework — one of the earliest applications of a Swin Transformer-based generator in CycleGAN, adapted specifically for histopathology images. It requires no paired images and no expert-selected reference or template image, instead learning the dataset's stain distribution in an unsupervised manner.

Result

Evaluated across four different datasets, the method generalizes well to staining conditions it wasn't trained on.
